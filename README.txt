LITTLE BIRTHDAY SURPRISE — PHOTO SCRAPBOOK EDITION

WHAT'S NEW
- Three scrapbook-style photo cards with a taped-photo look.
- Staggered entrance animation when the Memory Lane screen opens.
- Gentle hover lift/tilt effects.
- Tap/click a photo to open a larger lightbox view; close with the X, outside click, or Escape.
- Responsive layout for phones and desktops.
- If a photo file is missing, a cute emoji placeholder appears instead.

SETUP
1. Extract this folder.
2. Open the photos folder.
3. Put your own images there and name them photo1.jpg, photo2.jpg, and photo3.jpg.
4. Open index.html in a browser.
5. Click through to “A few things worth celebrating” to see the scrapbook.

PERSONALIZE CAPTIONS
In index.html, search for the text inside each memory card, such as “Your lovely smile”. Change the <strong> text and the <small> caption to whatever you like. Also update the image alt text and data-caption if you change the photo's subject.

CHANGE PHOTO FILENAMES
The first card uses src="photos/photo1.jpg", the second uses photos/photo2.jpg, and the third uses photos/photo3.jpg. If your file has another name or extension, update the matching src path in index.html. Keep the photos folder beside index.html.

MUSIC
The optional music player expects a file called music.mp3 beside index.html. Music is not included.

RUN LOCALLY
No installation or server is required for this version. Double-click index.html to open it in your browser.

PUBLISHING
You can upload the folder contents to a static hosting service such as GitHub Pages or Netlify. Keep the photos folder and its files in the same relative location. Only publish photos you have permission to share.
